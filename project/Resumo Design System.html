Resumo · Design System v1.0

Paper Design

Minimal, print-inspired, tactile. Built on warm neutrals, near-black primary actions, and a single purple accent. Every element earns its place.

Colors

One accent (purple), one primary (near-black), warm neutrals throughout. Semantic colors — success, warning, danger — appear only in functional contexts, never decoratively.

Spacing

Base-4 scale. Token names reflect multiples of 4px. Gap and padding should always use these values.

Border radius: 2px for inline chips, 3px for small controls, 4px for panels and modals, 6px for overlays. Never exceed 6px.

Buttons

Near-black primary. Ghost and secondary for lower-emphasis actions. Danger only for destructive, irreversible operations. Disabled state uses border background.

Cards & Panels

Panels use white background, 1px warm border, 4px radius. No drop shadows on in-page elements — shadow only on the modal overlay. Dividers replace visual depth.
